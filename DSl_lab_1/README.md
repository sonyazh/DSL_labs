## Theory

Chomsky Normal Form, usually called CNF, is a normalized form for context-free grammars. A grammar is in CNF when every production has one of these shapes:

```
A -> BC
A -> a
S -> epsilon
```

Here, `A`, `B`, and `C` are non-terminal symbols, `a` is a terminal symbol, and `S -> epsilon` is allowed only when the language generated by the grammar contains the empty word. In other words, CNF allows a rule to either produce one terminal symbol or exactly two non-terminal symbols. This makes the grammar easier to process by algorithms, because every derivation has a predictable binary structure.

To transform a grammar into CNF, several cleanup steps are usually required. First, epsilon productions are removed. An epsilon production is a rule like `C -> epsilon`, meaning that the symbol `C` can disappear from a derivation. When removing such rules, the algorithm must also add the variants that become possible because of that disappearance. For example, if `S -> AC` and `C` is nullable, then after removing `C -> epsilon`, the grammar must also include `S -> A`.

The next step is eliminating renaming, also called eliminating unit productions. A unit production has the form `A -> B`, where both sides are non-terminals. Such rules do not add terminals to the generated word directly, they only rename one non-terminal into another. To remove them, the algorithm finds what each non-terminal can reach through unit productions and copies the useful non-unit productions from those reachable symbols.

After that, inaccessible symbols are removed. A symbol is inaccessible if it cannot be reached from the start symbol through any sequence of productions. Such symbols do not affect the language of the grammar, because no derivation that starts from `S` can ever use them. In this variant, `D` is removed because it is never reached from the start symbol.

The algorithm also removes non-productive symbols. A non-terminal is productive if it can eventually derive a word made only from terminal symbols. If a non-terminal can never lead to a terminal string, then it cannot participate in a valid word of the language and should be removed together with productions that depend on it.

One small but important detail is the creation of a new start symbol. In the implementation, the old start symbol `S` is replaced by a fresh symbol such as `S0_1`, and the rule `S0_1 -> S` is added. This is useful because the original start symbol may appear on the right side of productions, for example in rules like `A -> bS` or `B -> bSa`. A separate start symbol protects the start of the grammar during normalization, especially while removing epsilon and unit productions. After unit production elimination, `S0_1` receives the productions of `S`, and it remains the official start symbol.

Finally, the productions are reshaped to match CNF. If a terminal appears inside a longer production, it is replaced by a helper non-terminal. For example, `b` can be represented by a new symbol like `T_b_1`, with the production `T_b_1 -> b`. Then a production such as `S -> bA` becomes `S -> T_b_1A`, which fits the `A -> BC` form. Long productions are also split into binary rules. For example, a production with three or four symbols on the right side is broken into several productions with exactly two non-terminals on the right side, using helper symbols such as `X_1`, `X_2`, and so on.

The grammar from the variant is:

```
G = (Vn, Vt, P, S)

Vn = { S, A, B, C, D }
Vt = { a, b }

P = {
    S -> bA
    S -> AC
    A -> bS
    A -> BC
    A -> AbC
    B -> CbaC
    B -> a
    B -> bSa
    C -> epsilon
    D -> AB
}
```

## Implementation description

The grammar is represented by the `Grammar` structure. It stores the set of non-terminals, the set of terminals, the productions, and the start symbol. A production body is represented as a vector of symbols, so the same implementation can work with productions of different lengths.

```cpp
using Symbol = std::string;
using ProductionBody = std::vector<Symbol>;

struct Grammar {
    std::set<Symbol> nonTerminals;
    std::set<Symbol> terminals;
    std::map<Symbol, std::set<ProductionBody>> productions;
    Symbol start;
};
```

The normalization logic is encapsulated in the `CnfNormalizer` class. Its public method receives a grammar, applies all CNF conversion steps, and returns the normalized grammar.

```cpp
class CnfNormalizer {
public:
    static Grammar normalize(const Grammar& input) {
        Grammar grammar = input;

        addFreshStart(grammar);
        eliminateEpsilonProductions(grammar);
        eliminateRenaming(grammar);
        eliminateNonProductiveSymbols(grammar);
        eliminateInaccessibleSymbols(grammar);
        replaceTerminalsInLongProductions(grammar);
        breakLongProductions(grammar);
        eliminateNonProductiveSymbols(grammar);
        eliminateInaccessibleSymbols(grammar);

        return grammar;
    }
};
```

The method `addFreshStart` creates a new start symbol before other transformations begin. This avoids special problems when the original start symbol appears on the right side of other productions.

```cpp
static void addFreshStart(Grammar& grammar) {
    const Symbol oldStart = grammar.start;
    const Symbol newStart = freshNonTerminal(grammar, "S0_");

    grammar.nonTerminals.insert(newStart);
    grammar.productions[newStart].insert({ oldStart });
    grammar.start = newStart;
}
```

The epsilon elimination step first finds all nullable non-terminals. Then it creates every useful variant of a production by optionally removing nullable symbols. Empty productions are not kept, except for the start symbol when needed.

```cpp
static void eliminateEpsilonProductions(Grammar& grammar) {
    std::set<Symbol> nullable;
    bool changed = true;

    while (changed) {
        changed = false;

        for (const auto& production : grammar.productions) {
            const Symbol& left = production.first;
            const std::set<ProductionBody>& bodies = production.second;

            for (const auto& body : bodies) {
                const bool bodyIsNullable = body.empty()
                    || std::all_of(body.begin(), body.end(), [&](const Symbol& symbol) {
                        return nullable.count(symbol) > 0;
                    });

                if (bodyIsNullable && nullable.insert(left).second) {
                    changed = true;
                }
            }
        }
    }
}
```

Renaming is eliminated by finding all non-terminals reachable through unit productions and copying their non-unit productions to the original non-terminal.

```cpp
static void eliminateRenaming(Grammar& grammar) {
    std::map<Symbol, std::set<ProductionBody>> normalized;

    for (const Symbol& source : grammar.nonTerminals) {
        std::set<Symbol> reachableByUnit{ source };
        std::queue<Symbol> queue;
        queue.push(source);

        while (!queue.empty()) {
            const Symbol current = queue.front();
            queue.pop();

            for (const ProductionBody& body : grammar.productions[current]) {
                if (body.size() == 1 && isNonTerminal(grammar, body[0])) {
                    if (reachableByUnit.insert(body[0]).second) {
                        queue.push(body[0]);
                    }
                }
            }
        }
    }
}
```

The final CNF-specific steps replace terminals inside longer productions and split long right sides into binary rules. For example, a terminal `b` inside a longer production is replaced by `T_b_1`, and `T_b_1 -> b` is added. Longer productions are then broken using helper symbols such as `X_1`.

```cpp
static void replaceTerminalsInLongProductions(Grammar& grammar) {
    std::map<Symbol, Symbol> terminalAliases;

    for (const Symbol& terminal : grammar.terminals) {
        const Symbol alias = freshNonTerminal(grammar, "T_" + terminal + "_");
        grammar.nonTerminals.insert(alias);
        grammar.productions[alias].insert({ terminal });
        terminalAliases[terminal] = alias;
    }
}
```
